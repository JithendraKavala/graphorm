# GraphORM Schema Specification & Language Reference

This document provides the definitive technical specification and grammar reference for the **GraphORM Schema Definition Language (DSL)**. GraphORM uses an intuitive, declarative, Prisma-inspired schema format (`schema.graphorm`) to define relational models, database-backed views, virtual join views, composite types, enums, security boundaries, and PostgreSQL DDL configurations.

---

## 1. Top-Level Declarations

A GraphORM schema file contains declarations of five kinds:
1. `datasource`: Database connection specification
2. `generator`: Target artifact and code generation configuration
3. `model`: Mutable relational entities mapped to physical database tables
4. `view`: Read-only projection entities (database-backed, virtual joined, or raw SQL subqueries)
5. `type`: Reusable composite value objects
6. `enum`: Strongly-typed enumeration definitions

```prisma
datasource db {
  provider = "postgresql"
  url      = "postgresql://localhost:5432/university_db"
}

generator client {
  provider = "graphorm-client-java"
  package  = "com.example.university"
}
```

## 2. Scalar Types

GraphORM maps schema scalar types to PostgreSQL column types and Java 21 primitives/records:

| GraphORM Type | PostgreSQL Type | Java 21 Type | GraphQL Scalar | Notes |
|---|---|---|---|---|
| `Int` | `INTEGER` / `INT4` | `Integer` | `Int` | 32-bit signed integer |
| `BigInt` | `BIGINT` / `INT8` | `Long` | `BigInt` / `String` | 64-bit signed integer |
| `String` | `TEXT` / `VARCHAR` | `String` | `String` | Textual data |
| `Boolean` | `BOOLEAN` | `Boolean` | `Boolean` | True / false |
| `Float` | `DOUBLE PRECISION` / `FLOAT8` | `Double` | `Float` | 64-bit IEEE floating point |
| `Decimal` | `NUMERIC` / `DECIMAL` | `java.math.BigDecimal` | `BigDecimal` / `Float` | Arbitrary precision currency/math |
| `DateTime` | `TIMESTAMPTZ` / `TIMESTAMP` | `java.time.Instant` | `DateTime` / `String` | ISO-8601 UTC timestamp |
| `Date` | `DATE` | `java.time.LocalDate` | `Date` / `String` | Calendar date |
| `Time` | `TIME` | `java.time.LocalTime` | `Time` / `String` | Time of day without timezone |
| `UUID` | `UUID` | `java.util.UUID` | `ID` / `String` | RFC-4122 UUID |
| `Json` | `JSONB` / `JSON` | `String` / `Map<String, Object>` | `JSON` | Binary JSON |
| `Bytes` | `BYTEA` | `byte[]` | `String` (Base64) | Binary payload |

### Type Modifiers
- **Optional (`?`)**: Allows null values (e.g. `gpa Float?`). Non-optional fields default to `NOT NULL`.
- **List (`[]`)**: Represents 1:N or N:M relationships (e.g. `students Student[]`) or array columns.

## 3. Models & Field Attributes

A `model` defines a physical database table with write support (CRUD operations):

```prisma
model Student {
  id           Int         @id @default(autoincrement())
  uuid         UUID        @default(uuid())
  name         String      @map("full_name")
  email        String      @unique
  gpa          Float?
  version      Int         @default(1) @version
  secretNotes  String?     @auth(roles: ["ADMIN", "INSTRUCTOR"])
  tenantId     String      @injected(from: "tenant_id")
  departmentId Int         @map("department_id")
  department   Department? @relation(fields: [departmentId], references: [id], onDelete: Cascade)
  createdAt    DateTime    @default(now())

  @@map("students")
  @@index([departmentId], name: "idx_students_department")
  @@check("gpa >= 0.0 AND gpa <= 4.0", name: "chk_student_gpa_range")
}
```

### Field Attributes Reference

- `@id`: Marks the single-column primary key.
- `@default(...)`: Declares default values:
  - `@default(autoincrement())`: PostgreSQL `SERIAL` / `GENERATED BY DEFAULT AS IDENTITY`.
  - `@default(uuid())`: Generates a UUID v4 (`gen_random_uuid()`).
  - `@default(now())`: Current database timestamp (`CURRENT_TIMESTAMP`).
  - `@default("literal")` or `@default(42)`: Static default literal.
- `@unique`: Creates a unique constraint and index on the column.
- `@map("column_name")`: Maps the schema field name to a different physical database column name.
- `@db.*`: Native PostgreSQL type overrides (e.g. `@db.VarChar(100)`, `@db.Text`, `@db.SmallInt`).
- `@version`: Marks an integer column as an optimistic lock version counter. Updates automatically check `WHERE version = ?` and increment `version = version + 1`, throwing `OptimisticLockException` if concurrent modifications occur.
- `@injected(from: "context_key")`: Excludes the field from client mutation inputs and automatically populates it from server-side security/request context (e.g., `tenant_id`, `current_user_id`). Prevents parameter tampering.
- `@auth(roles: ["ROLE_A", "ROLE_B"])`: Restricts access to the specific field to users possessing at least one of the listed roles. Unauthorized queries receive sanitized errors.

## 4. Block Attributes Reference

Block attributes are declared inside a `model` or `view` using `@@`:

- `@@map("table_or_view_name")`: Sets the underlying physical table or view name in PostgreSQL.
- `@@id([field1, field2])`: Declares a composite primary key.
- `@@unique([field1, field2], name: "idx_name")`: Declares a composite unique constraint.
- `@@index([field1, field2], name: "idx_name", type: BTree)`: Declares a secondary index. Supported index types: `BTree`, `Hash`, `GIN`, `GiST`.
- `@@check("expression", name: "chk_name")`: Declares a PostgreSQL `CHECK` constraint.
- `@@auth(roles: ["ADMIN"])`: Restricts all queries and mutations for this model/view to users with specified roles.
- `@@readonly`: Designates a physical table as strictly read-only. GraphORM code generators omit mutation inputs and runtime builders throw `ReadOnlyViewException` on write attempts.
- `@@expose(queries: true, mutations: false)`: Fine-grained control over GraphQL root schema exposure.

## 5. Relationships

GraphORM supports 1:1, 1:N, and N:1 relations using the `@relation` attribute:

```prisma
model Department {
  id       Int       @id @default(autoincrement())
  name     String
  students Student[] // 1:N inverse relation
}

model Student {
  id           Int        @id @default(autoincrement())
  departmentId Int
  department   Department @relation(fields: [departmentId], references: [id], onDelete: Cascade, onUpdate: Cascade)
}
```

### Referential Actions:
- `onDelete: Cascade | SetNull | Restrict | NoAction`
- `onUpdate: Cascade | SetNull | Restrict | NoAction`

## 6. Schema-Defined View Models

GraphORM views are strictly read-only projection entities. They prevent writes at compile time and runtime.

### Category 1: Database-Backed Views (`@@view`)
Target existing PostgreSQL physical views:

```prisma
view DepartmentStats {
  departmentName String @map("department_name")
  studentCount   Int    @map("student_count")
  courseCount    Int    @map("course_count")

  @@view
  @@map("v_department_stats")
}
```

### Category 2: Virtual Join Views (`@@from`, `@@leftJoin`, `@@innerJoin`)
GraphORM compiles virtual views directly into single pushdown SQL queries with joins and aggregations without requiring a physical database view:

```prisma
view StudentDashboard {
  studentId      Int     @map("s.id")
  studentName    String  @map("s.name")
  departmentName String? @map("d.dept_name")
  courseCount    Int     @aggregate(count: "e.id")
  avgGrade       Float?  @aggregate(avg: "e.grade_points")

  @@from(Student, as: "s")
  @@leftJoin(Department, as: "d", on: "s.departmentId == d.id")
  @@leftJoin(Enrollment, as: "e", on: "s.id == e.studentId")
  @@groupBy(["s.id", "s.name", "d.dept_name"])
}
```

### Category 3: Raw SQL Subquery Views (`@@query`)
For complex queries involving `UNION`, `UNION ALL`, CTEs, or window functions:

```prisma
view CourseEnrollmentRanking {
  courseId    Int
  courseTitle String
  totalUnits  Int
  rank        Int

  @@query("SELECT c.id AS \"courseId\", c.title AS \"courseTitle\", COUNT(e.id) AS \"totalUnits\", DENSE_RANK() OVER (ORDER BY COUNT(e.id) DESC) AS \"rank\" FROM courses c LEFT JOIN enrollments e ON c.id = e.course_id GROUP BY c.id, c.title")
}
```

## 7. Composite Types and Enums

```prisma
enum EnrollmentStatus {
  ENROLLED
  WAITLISTED
  COMPLETED
  DROPPED
}

type Address {
  street  String
  city    String
  state   String
  zipCode String
}

model Instructor {
  id      Int      @id @default(autoincrement())
  name    String
  address Address  // Embedded composite value object
}
```
