# M0 — Repository Foundation

**Status:** 🟡 In Progress
**Branch:** `feat/m0-repository-foundation`

## Objective

Establish a working, maintainable project foundation. Every subsequent milestone builds on this. If the foundation is weak, everything else suffers.

## Expected Deliverables

1. All required Maven modules declared and building
2. Complete engineering documentation in `docs/`
3. Complete GitHub project management configuration
4. CI pipeline running on PR creation
5. A new developer can clone the repo and build it in under 5 minutes

---

## Acceptance Criteria

- [ ] `mvn clean verify` succeeds from the repository root
- [ ] All modules compile without errors
- [ ] CI executes on pull requests and push to `main`
- [ ] No module has circular dependencies (verified with `mvn dependency:analyze`)
- [ ] A new developer can understand how to build and test the project using the README
- [ ] All required documentation files exist and are substantive (not empty placeholders)
- [ ] All GitHub templates exist and are filled in
- [ ] The PR template is complete

---

## Required Tests

At M0, the testing requirement is minimal:
- Each module must have a `src/test/java` directory
- At minimum, a "placeholder" test class that confirms the module compiles and JUnit 5 is correctly configured
- No integration tests are required at M0 (Testcontainers will be used from M3 onward)

---

## Out of Scope

- Any domain model implementation
- Any SQL execution
- Any GraphQL wiring
- Any Spring Boot configuration
- Any schema parsing
- Any code generation
- Code formatting enforcement plugins (Checkstyle, Spotless) — may be added in M0 if straightforward, but not a blocker

---

- [ ] PR is merged to `main`
- [ ] Roadmap is updated to 🟢 Done
