# M11 — Stabilization and Release

**Status:** ⚪ Not Started
**Depends on:** M10

---

## Objective

Prepare GraphORM for external adoption. After M11, the framework is ready for 1.0.0 release: APIs are stable, documented, tested, and free of known critical or high-severity defects.

---

## Scope

### API Review
- Review all public APIs across all modules
- Identify and remove unnecessary public APIs
- Identify and fix inconsistencies in naming, parameter order, return types
- Mark deprecated APIs if backward-compatible removal is needed

### Error Message Review
- Review all exception messages for clarity and actionability
- Ensure all schema validation errors include line:column context
- Ensure all SQL errors are translated to meaningful exception types
- Ensure configuration errors explain what is missing and how to fix it

### Security Review
- Verify parameterized SQL in all query paths (automated + manual audit)
- Verify no sensitive fields are exposed by default
- Verify GraphQL complexity and depth limits are implemented and configurable
- Verify no credentials or sensitive values in logs
- Threat-model review

### Performance Profiling
- Run JMH benchmarks on key operations
- Profile against Nexus Commerce workload
- Identify and resolve any P0/P1 performance regressions
- Document performance characteristics and known limits

### Documentation Review
- Review all public API Javadoc
- Review all `docs/` markdown for accuracy and completeness
- Review README for correctness from a clean project (no prior knowledge)
- Write migration guide if any API changed between pre-release and 1.0

### Compatibility Testing
- Test with Java 21
- Test with Spring Boot 3.2 and 3.3
- Test with PostgreSQL 14, 15, and 16
- Test with Testcontainers latest

### Versioning and Release Process
- Finalize version 1.0.0
- Tag and publish release artifacts
- Publish to Maven Central (or document the publication process)
- Create GitHub Release with changelog

### Final Verification
- All CI checks green on `main`
- Full test suite passes (unit + integration)
- No `TODO` without issue reference
- No disabled tests
- No commented-out code
